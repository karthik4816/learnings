# Day 3 - Strings

## What is a String?

A string is a sequence of characters enclosed in single or double quotes.

Example:

```python
name = "Python"
```

---

## Indexing

```python
name[0]
name[-1]
```

---

## Slicing

```python
name[1:4]
name[:3]
name[2:]
```
