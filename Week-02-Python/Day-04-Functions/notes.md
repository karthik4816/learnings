# Day 4 - Functions

## What is a Function?

A function is a reusable block of code that performs a specific task.

Instead of writing the same code multiple times, you write it once inside a function and call it whenever needed.

---

## Syntax

```python
def function_name():
    # code
```

---

## Parameters

Parameters allow data to be passed into a function.

Example:

```python
def greet(name):
    print(name)
```

---

## Return

The `return` statement sends a value back to the caller.

```python
def add(a, b):
    return a + b
```

---

## Scope

- Local variables exist only inside a function.
- Global variables can be accessed from outside the function.

---

## Built-in Functions

- print()
- input()
- len()
- type()
- max()
- min()

---

## User-defined Functions

Functions created using the `def` keyword.
