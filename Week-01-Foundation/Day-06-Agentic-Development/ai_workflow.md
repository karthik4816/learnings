# AI Workflow

## When AI Helps

 Explaining compiler or runtime errors

 Reviewing Git workflows

 Generating practice questions

 Explaining difficult concepts

 Improving documentation

---

## When AI Hurts

    Copying code without understanding it

    Completing assignments without learning

    Depending on AI for every small problem

    Skipping debugging practice

---

## My AI Workflow

1. Read the error myself.
2. Try solving it.
3. If stuck, ask AI for an explanation.
4. Understand the solution.
5. Apply the fix myself.
6. Test the solution.
7. Commit the changes.
