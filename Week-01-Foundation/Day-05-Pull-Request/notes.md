## What is a Pull Request?

A Pull Request (PR) is a request to merge changes from one branch into another. It allows code to be reviewed before it becomes part of the main branch.


## Pull Request Workflow

1. Create a branch.
2. Make changes.
3. Commit the changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Review the code.
7. Merge into `main`.
8. Delete the feature branch.
